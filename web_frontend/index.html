How It Works

  • Depth Estimation: Analyzes the image to estimate scene depth
  • Transmission Map: Models wavelength-dependent light absorption and scattering
  • Physical Model Inversion: Corrects color distortion using physics-based principles
  • Degradation-Aware Refinement: Focuses enhancement on degraded regions while preserving details

Note: This is a software-only system. No hardware sensors or external devices are required. The model has been trained on paired underwater images to learn the enhancement mapping.
